8) السلامة
----------
- التطبيق يعلن أنه لا يستضيف المحتوى وأن المستخدم يثبت المصادر يدوياً، لكن runtimes المحلية تحمل أو تشغل APK و.cs3 وJavaScript؛ لذلك لا تُعامل الإخلاءات العامة كضمان تقني.
- SECURITY.md يضع وصول المصدر/الإضافة إلى filesystem أو keystore أو cookies أو runtime ضمن نطاق الثغرات، لكن لم يُختبر ذلك ديناميكياً.
- لم يُشغّل أي كود مجهول أو APK أو provider، التزاماً بالسلامة؛ لذلك لا يمكن تقييم payloads أو سلوك الشبكة أو العزل.
- لا يوجد دليل متحقق على تصنيف عمري رسمي أو حد أدنى للعمر أو parental controls.
- لا يمكن إثبات سلامة توقيعات APK أو artifacts أو نتائج CI من الفهرس فقط.
- لا يمكن إثبات فعالية PIN أو biometric lock أو AES-encrypted-at-rest دون اختبار مضبوط.
- adult_count لا يمثل تصنيفاً شاملاً للمحتوى الخارجي.

-----------------------------

- وجود descriptor أو status في فهرس لا يساوي نجاح التشغيل داخل Sozo.

- لم يتحقق الفحص من manifest العام أو repository لبعض إضافات Stremio، لذلك وُسمت تلك الحقول بغير متحقق بدلاً من التخمين.
- لم يمكن استخراج مقارنة Git HTML وعدد commits ahead/behind بدقة.

أخطاء أو إخفاقات المحاور المبلّغ عنها:
- لم تُسجل إخفاقات محاور صريحة؛ الحقل الوارد كان فارغاً.
- مع ذلك، سجّلت المحاور قيوداً تشغيلية وفهرسية عديدة، وقد أُبقيت في هذا التقرير كقيود لا كحقائق ناقصة.

17) تصحيح الفحص المحلي للنسخة المعدلة Sozo Gold
------------------------------------------------
بعد انتهاء الفحص العام للصفحات العامة، تمت مراجعة شجرة العمل المحلية للفرع gold-development حتى لا يُخلط بين عدم ظهور التكامل في README وبين وجوده في الشيفرة.

- Vega موجود فعلياً في النسخة المعدلة عبر:
  - lib/features/vega/data/vega_repo_store.dart
  - lib/features/vega/presentation/pages/vega_sources_page.dart
  - lib/features/vega/presentation/pages/vega_provider_page.dart
  - lib/features/extensions/data/mangayomi_runtime.dart
  - lib/features/sources/data/builtin_extension_sources.dart
- المستودع المدمج افتراضياً لـVega هو Zenda-Cross/vega-providers، ويُعاد تحديثه إذا كان محفوظاً بلا مزود صالح.
- Stremio موجود فعلياً عبر:
  - lib/features/stremio/data/stremio_addon_client.dart
  - lib/features/stremio/data/stremio_addon_store.dart
  - lib/features/stremio/presentation/pages/stremio_addons_page.dart
  - lib/features/sources/data/builtin_extension_sources.dart
- عناوين Stremio المدمجة في Sozo Gold هي Cinemeta وOpenSubtitles وTorrentio. يتم التطبيع والحفظ محلياً، وتُتجاوز الإضافة غير المتاحة دون تعطيل بدء التطبيق.
- لذلك تُصحح ملاحظة محور Vega ومحول Stremio: التكامل موجود في Sozo Gold على مستوى إدارة المستودع/الفهرس والواجهة والجلب، لكن لم يتم تشغيل كل provider أو addon خارجياً في هذه المراجعة لأسباب السلامة. وجود التكامل لا يساوي إثبات نجاح كل مصدر.
- اختبار قارئ المانغا بعد التعديل الأخير نجح محلياً، كما نجح flutter analyze للملف المعدل دون أخطاء.
